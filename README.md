## 🔥 Features
- Supports ESX, QB 
- Supported creation of all custom crafting for jobs
- Supported system of setting access elements for crafting.
- Template in config.templates.lua
  Police / Illegal / Bahama
- Custom selection of table / fridges for production supported
- Customizable notifications ( Default settings for OX - ox_inventory / ox_lib ) 
   
## 🛠️ Dependencies
- [ox_lib](https://github.com/overextended/ox_lib)
- [ox_inventory](https://github.com/overextended/ox_inventory)
  
## 📲 Installation
1. Download latest release or source code
2. Extract the .zip file
3. Copy the folder to your server resources folder
4. Add `ensure mrw_crafting` to your server.cfg
5. Restart the server
